# 🎙️ Podcast Manager API

Projeto desenvolvido durante o desafio da DIO com o objetivo de criar uma API utilizando Node.js e TypeScript sem frameworks.

---

## 📚 Objetivo

Construir uma API simples para gerenciamento de podcasts, aplicando conceitos de:

- Node.js
- TypeScript
- Rotas HTTP
- Manipulação de JSON
- Organização de projetos backend
- Criação de API sem frameworks

---

## 🚀 Tecnologias Utilizadas

- Node.js
- TypeScript
- TSX

---

## 📂 Estrutura do Projeto

```bash
src/
 ├── controllers/
 ├── services/
 ├── repositories/
 ├── routes/
 ├── utils/
 └── server.ts
```

---

## ⚙️ Como Executar o Projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 2️⃣ Instalar dependências

```bash
npm install
```

### 3️⃣ Executar o projeto

```bash
npm run start:dev
```

---

## 📌 Rotas da API

### Buscar episódios

```http
GET /api/list
```

### Filtrar podcasts

```http
GET /api/episode?p=nome
```
